Site Plan: AltruTask Remote

Galo - WDD 131 Final Project

1. Site Name

Name: AltruTask Remote

Reasoning: This name clearly communicates the platform's dual focus: altruism (helping people) and remote micro-tasks. It is memorable and clearly targets users looking for meaningful online work.

Domain Availability: altrutask-remote.org

2. Site Purpose

The site provides a central hub for users seeking remote micro-task opportunities that directly support non-profits and community organizations. It will feature a job board, user registration, and resources for executing tasks efficiently from home.

3. Scenarios

  • "How can I find flexible, remote micro-tasks that fit into my schedule while allowing me to help others?"
  • "What skills are required to sign up for community-focused digital newsletters and data entry tasks?"

4. Color Schema

The colors chosen represent trust, clarity, and action.

  • Primary Blue (#2C3E50): Used for headings, headers, and footers to establish trust and professionalism.
  • Action Green (#27AE60): Used for buttons, links, and calls to action, symbolizing growth and positive impact.
  • Background Off-White (#F8F9FA): Used for the main body background to keep the site clean and highly readable.

5. Typography

We are using two highly readable Google Fonts to ensure a modern, accessible experience:

  • Heading Font: Montserrat. Used for `h1`, `h2`, and `h3` tags to provide a strong, clean structural hierarchy.
  • Body Font: Open Sans. Used for paragraphs and lists to ensure excellent legibility on mobile and desktop screens.

6. Wireframes

The wireframes define the structural layout of the home page for different viewports.

Mobile View: Stacked layout, hamburger menu, single-column task feed.

Desktop View: Horizontal navigation, two-column layout (Task Feed on the left, User Dashboard on the right).
